# 纠正跑调「声音驾驶舱」Web 应用 — 设计文档

**日期**：2026-06-11
**状态**：草案，待用户审阅
**作者**：与用户协作 brainstorm

---

## 1. 背景

用户写了一份「歌唱跑调『一小时极速纠正』教学法（完整终极版）」，方法核心是把抽象的"音准"转成具体的"声音驾驶"体感，让学员在 60 分钟内打通"听"与"控"的任督二脉。

目标：把教程最核心的四个训练方法做成可独立使用的 Web 应用，让更多人受益。

## 2. 教学法核心（来自教程）

**六大卡点**：概念混淆、听觉盲区、体感缺失、感知模糊、控制粗糙、恶性循环。

**三步训练**：
1. 声音车辆启动（引擎滑音）
2. 共振对齐锚定（捕捉"啪"的融合瞬间）
3. 三项驾驶精修：直线巡航 / 平滑变道 / 盲操停车

## 3. MVP 范围

覆盖教学法四个最具差异化价值的训练：

| 模式 | 训练目标 | 对应教程步骤 |
|---|---|---|
| 引擎滑音 | 自由滑音，曲线越平滑越好 | 第 1 步 |
| 直线巡航 | 长音稳定在目标音 | 第 3 步「直线巡航」 |
| 共振对齐 | 感受"两个音变成一个音"的听感 | 第 2 步 |
| 跟唱旋律 | 跟着内置旋律唱，实时对偏差 | 第 3 步 C「上路实战」 |

### 3.1 明确不做

- ❌ 账号 / 用户系统
- ❌ 进度跟踪 / 数据持久化
- ❌ 录音回放
- ❌ 5 日练习表
- ❌ 后端 / 服务器
- ❌ 平滑变道（音间滑音"彩虹桥"）
- ❌ 盲操停车模式
- ❌ 自定义旋律上传 / 任意歌曲跟唱
- ❌ 详细评分报告（哪个音最不准等）

这些属于"完整版"，等 MVP 验证后再迭代。

## 4. 技术架构

**栈**：纯静态文件，零构建，零后端。

| 用途 | 方案 |
|---|---|
| 麦克风采集 | Web Audio `getUserMedia` + `AudioContext` + `AnalyserNode` |
| 实时音高检测 | `pitchy` 库（YIN 算法，~3KB，MIT） |
| 参考音播放 | Web Audio `OscillatorNode`（sine 波） |
| 音高→音名 | 12-TET 公式（自写） |
| 可视化 | Canvas 2D |
| 部署 | 静态文件托管（或本地双击 `index.html`） |

## 5. 四种模式详细规格

### 5.1 引擎滑音（Engine Glissando）

- **目标**：让用户感受如何"驾驶"声音上下移动；学会用平滑的频率变化取代跳跃式发声
- **UI**：
  - Canvas 显示实时音高曲线
  - 横轴 = 时间（最近 5 秒滚动窗口）
  - 纵轴 = 音高（用音分 cents 表示，避免跨越八度时画面"反转"）
- **反馈**：
  - 实时显示 "平滑度" 分数 = `1 - min(曲线斜率标准差, 阈值) / 阈值`（百分比，阈值取 50 cents/帧）
  - 不显示"偏离"（自由模式没有目标）
- **可调**：无（自由模式）
- **结束**：用户点击「停止」

### 5.2 直线巡航（Straight Cruise）

- **目标**：长音稳定在目标音附近
- **UI**：
  - Canvas 显示目标线（水平虚线）+ 用户音高曲线
  - 横轴 = 时间；纵轴 = 音分（相对目标音的偏离）
- **可调**：
  - 目标音（C4~C5 范围内可选，默认 A4 = 440Hz）
- **反馈**：
  - 实时显示 cents 偏离（-50 ~ +50 cents，超出范围继续显示实际值）
  - 实时显示"稳定度"分数 = `1 - min(标准差, 50) / 50`（百分比，标准差 = 最近 2 秒窗口内 cents 偏离的标准差）
- **结束**：用户点击「停止」

### 5.3 共振对齐（Resonance Alignment）

- **目标**：让用户身体记住"准"是"两个音变成一个音"的感觉
- **流程**：
  1. `LISTENING` —— 提示「请发一个稳定的『啊』」；监测麦克风
  2. `LOCKED` —— 音高在 100 cents 窗口内稳定 1 秒后锁定；显示「已锁定 X 音 @ Y Hz」
  3. `PLAYING` —— 创建 `OscillatorNode`（sine 波，gain ≈ 0.2）；起始频率 = `用户音高 × 2^(-3/12)`；用 `linearRampToValueAtTime` 在 3 秒内平滑升到用户音高
  4. `FUSED` —— 到达目标频率后停顿 0.5 秒；显示「感受到了吗？那就是『准』的感觉」
  5. 用户可点击「再来一次」或「换一个音」回到 `LISTENING`
- **UI**：
  - 横轴 = 时间（0 ~ 3.5 秒，从按下"开始发声"算起）
  - 纵轴 = 频率（Hz）
  - 用户曲线 = 绿色
  - 参考曲线 = 橙色
  - 两者汇合时标金色光晕
  - 状态文字在 Canvas 上方
- **可调**（MVP 写死默认值，不暴露 UI）：
  - 起始间隔：**3 个半音**（小三度）
  - 滑升时长：**3 秒**
  - 锁定阈值：100 cents 窗口内稳定 1 秒
- **结束**：用户在 `FUSED` 后点击「停止」

### 5.4 跟唱旋律（Follow Melody）

- **目标**：对照内置旋律唱，实时高亮跑调处
- **硬件要求**：**用户戴耳机**（系统会提示）
- **内置旋律**（2 首，写死在 `app.js` 的 `MELODIES` 数组）：
  - 「生日快乐」(Happy Birthday)
  - 「小星星」(Twinkle Twinkle Little Star)
  - 每首用 `{note: "C4", start: 0.0, duration: 0.5}` 数组表示
- **流程**：
  1. `CHOOSE_MELODY` —— 显示 2 个旋律选项，用户选一首
  2. `COUNTDOWN` —— 倒计时 3-2-1
  3. `SINGING` —— 同时：
     - 应用用 `OscillatorNode`（sine 波，gain ≈ 0.2）按 `start/duration` 调度播放旋律
     - 应用持续检测用户音高
     - 每帧比对：根据当前时间找到期望音符，计算 cents 偏离
     - 用户曲线颜色 = `|cents| < 50 ? 绿 : 红`
     - 累计"在调帧数"和"总帧数"，实时显示准确率
  4. `RESULT` —— 旋律播完后显示最终准确率 + 「再来一次」按钮
- **UI**：
  - 横轴 = 时间（0 ~ 旋律总时长）
  - 纵轴 = 频率（Hz）
  - 目标曲线 = 橙色（按旋律音符阶梯化）
  - 用户曲线 = 绿/红（实时）
  - 当前音符名显示在顶部
  - 右上角实时准确率
- **音频细节**：
  - 音符之间用短 envelope（5ms attack/release）避免爆音
  - 总音量 ≤ 0.3，确保不刺耳
  - 提示用户戴耳机是为了"伴奏不漏到麦克风"
- **结束**：旋律自然结束进入 `RESULT`；用户也可中途点「停止」

### 6.1 视觉风格

- **背景**：深色（深蓝 `#0f172a` / 深灰 `#1e293b`），长时间练习不刺眼
- **主色**：
  - 用户曲线 = 绿 `#10b981`
  - 参考曲线 = 橙 `#f59e0b`
  - 目标线 = 白 `#f1f5f9`
  - 重合点 = 金 `#fbbf24`
- **字体**：大号无衬线（系统默认 sans-serif，移动端友好）

## 7. 错误处理

| 场景 | 处理 |
|---|---|
| 麦克风权限被拒 | 顶部红色横幅：「请在浏览器设置中允许麦克风访问」+ 简要指引 |
| 浏览器不支持 Web Audio | 启动前检测；不支持则显示「请用 Chrome / Edge / Safari 最新版」 |
| 静音 / 无输入 | 检测到 0.5 秒静音，自动提示「听不清，请再发一次」 |
| 共振对齐：用户音高不稳 | 锁定失败时提示「再稳一点」并重置到 `LISTENING` |
| HTTPS 问题 | 本地 `localhost` 自动允许；生产部署强制 HTTPS |

**原则**：每种错误给**可操作的指引**，不只说"出错了"。

## 8. 测试方法

MVP 阶段**手动测试**足够，四模式各一组验证：

**1. 引擎滑音**
- ✅ 用钢琴/哼鸣从低到高滑：曲线应**平滑无锯齿**
- ✅ 故意"跳台阶"唱：曲线应出现明显锯齿

**2. 直线巡航**
- ✅ 对着定音器唱一个长 A4：偏离应稳定在 ±10 cents
- ✅ 故意偏低 50 cents：应显示 "-50 cents"

**3. 共振对齐**
- ✅ 稳定发一个 A4：参考音从 F4 平滑滑到 A4（约 3 秒）
- ✅ 融合点应**清晰可辨**（听感上"啪"一下；视觉上曲线重合）
- ✅ 重复 3 次都应一致

**4. 跟唱**
- ✅ 选「生日快乐」，戴耳机，3-2-1 后开始
- ✅ 跟唱准确：用户曲线**绿色**，准确率 > 70%
- ✅ 故意跑调：用户曲线**红色**高亮，准确率显著降低
- ✅ 旋律播完自动显示最终准确率
- ✅ 「再来一次」可重置

**跨浏览器**：Chrome / Edge / Safari 桌面 + 移动各跑一遍
